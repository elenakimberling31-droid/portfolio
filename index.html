Introduction to New Media


Code and Technology Narrative

For my exploration of code and technology, I realized just how little I had delved into the world of code. I breifly worked with scratzh but other than that most of my technology narrative was playing games of some sort.

New Media and Webtext Experiment

For the media and webtext experiment I wanted to use the tools I had already learned and place my own interests within it. So I decided to do a sort of overview of creating a dress and found it quite exciting to create something like this.

Multi-Page Webtext Design

In my multi page website I wanted to talk about artificial intelligence. It is something I firmly am against and I feel like so many people don't know the truth of its horrors. So I wanted to emulate Plato's cave and discuss this idea that once you know you can't go back and no one really cares.

Course Goals


1. Consider technology’s role in acts of making

Creation is something I am very used to, just not in the digital world. The use of code allows us to create tangible things virtually. Through this class I learned how much of creativity and creation I can actually put into code. It isn't only very strict things but room for some personal interest as well.

2. Embrace experimentation

With these three projects I found myslef experimenting a lot. So much of the code we were given I did not remotely understand. So I spent a lot of time copying code and deleting and creating new lines of binary. And so many times either nothing happened or it would mess it up completely. There are still so much I don't understand about code but I do feel like I have reached a good enough starting point to hopefully move forward to new projects.

3.Engage with others in a workshop environment

I really enjoyed the workshop environment as it often helped me with things I was confused with. Or would even make me realize it wasn't only me that had these issues. I discussed how I couldn't get my code to work or that there were a few aspects of the project I didn't understand how to do. I would be met with either agreeance or advice on how to fix it which was very helpful.

4. Practice revision within and across media forms
